Full Database Snapshot (.db file) — recommended

Full data moves now use a SQLite database file instead of Excel — the same reliable format the app itself runs on. A snapshot is an exact copy of the whole database (schema, every table, all rows, users included), so nothing is lost to sheet limits, date/type coercion or duplicate names. An import first cleans all data out of this app (after an automatic backup), then copies the file's data in with original IDs — no broken links, no orphans.
